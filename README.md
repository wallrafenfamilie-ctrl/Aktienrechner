Aktien-Cockpit 4.5

Vor Installation Backup aus bestehender App exportieren. Alle sieben Dateien im GitHub-Pages-Repository ersetzen. Nicht deinstallieren und Browserdaten nicht löschen.

Neue Funktionen: untere Navigation, Käufe/Nachkäufe, FIFO-Teilverkäufe, tatsächlicher Steuerabzug, einfache Steuerschätzung und Aktienverlusttopf, ETF-Jahresziel, Monatsstatistik, Backup inkl. Trades.

Wichtig: Vorhandene manuelle Gewinnbuchungen werden NICHT automatisch entfernt. Bei historisch nachgetragenen Trades alte Gewinnbuchungen erst nach Vergleich entfernen, sonst doppelte Gewinne. Steuerberechnung ist vereinfacht, tatsächliche Brokerabrechnung ist maßgeblich.

Offline-App ohne automatische Kursdaten.
